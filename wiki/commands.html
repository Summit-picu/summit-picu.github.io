picu Command Reference

Command Purpose
picu add <pkg> Install a package.
picu cook <pkg> Build a package from source.
picu cut <pkg> Remove a package and isolated dependencies.
picu find <query> Search connected mirrors.
picu sync Synchronize mirror metadata.
picu rebase Rebuild or reinstall the LFS base.
picu list List installed packages.
picu info <pkg> Show package or mirror information.
picu update Update packages, picu and trust data.
picu trust Manage trusted mirror keys.
picu help Show interactive help.

$ picu find Vim
