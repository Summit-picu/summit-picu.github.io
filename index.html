Package management

Meet picu.

The package manager designed around Summit Linux.

picu manages repositories, source recipes, binary packages, signatures, trust stores and package databases. 

$ picu sync
 fetching repositories
 verifying signatures
 updating package indexes
 Sync completed successfully

$ picu add vim
 finding in mirror
 checking version
⣾ installing Vim
