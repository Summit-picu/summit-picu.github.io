picu

picu is the package manager at the core of Summit Linux. It handles source builds, binary packages, repositories, signatures and package metadata.

Source code GitHub

Core commands 

picu add <pkg>
picu cook <pkg>
picu cut <pkg>
picu find <query>
picu sync
picu rebase
picu list
picu info <pkg>
picu update
picu trust
picu help

Source builds

Packages are described using declarative recipes .picu .

Binary packages

picu can install signed binary archives after checking their hashes and signatures.

Trust

Unsafe repositories are blocked by default.
Installing from an unsafe mirror requires an explicit flag --allow-unsafe .
