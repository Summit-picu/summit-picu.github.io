picu

picu is the package manager at the centre of Summit Linux. It handles source builds, binary packages, repositories, signatures and package metadata.

Core commands

picu add <pkg>
picu cook <pkg>
picu cut <pkg>
picu find <query>
picu sync
picu rebase
picu list
picu info <pkg>
picu update
picu trust
picu help

Source builds

Packages can be described using declarative .picu recipes.

Binary packages

picu can install signed binary tarballs after validating their hashes and signatures.

Trust

Unsafe repositories are blocked by default.
An explicit --allow-unsafe override is required to install from an unsafe mirror.

Example

$ picu find Vim

Vim
Comment: Vi improved code editor
Mirror: Summit Official
Versions: 0.1 1.0 13.12 23.12
Type: Src & Bin

$ picu add Vim
