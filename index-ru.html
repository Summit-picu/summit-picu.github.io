            Философия Summit
            
Построен с нуля.

            

              Summit Linux следует принципам Linux From Scratch: прозрачные
              компоненты, контролируемая сборка и минимум лишнего софта.
            

          

          

            

              

                
              

              
LFS / На основе исходников

              

                Summit построен на основе Linux From Scratch и сборки системы из
                исходников.
              

            

            

              

                
              

              
picu

              

                Пакетный менеджер, способный собирать из исходников,
                устанавливать бинарные пакеты, управлять репозиториями и
                выполнять криптографическую проверку.
              

            

            

              

                
              

              
Доверие по умолчанию

              

                Подписанные зеркала, доверенные ключи, поддержка CRL и защита от
                отката версий.
              

            

          

        

      

      

        

          

            Управление пакетами
            
Знакомьтесь: picu.

            
Пакетный менеджер, созданный специально для Summit Linux.

          

          

            
            

              picu управляет репозиториями, рецептами сборки, бинарными
              пакетами, подписями, хранилищами доверия и базами пакетов.
            

          

          

              

                
              

              
$ picu sync
[ OK ] получение репозиториев
[ OK ] проверка подписей
[ OK ] обновление индексов пакетов
[ OK ] синхронизация завершена
$ picu add vim
[ OK ] поиск в зеркале
[ OK ] проверка версии
[ .. ] установка Vim
