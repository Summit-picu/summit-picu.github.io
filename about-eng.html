Summit Linux is an independent Linux distribution built from source following Linux From Scratch principles.

Philosophy: transparency instead of magic, a recipe instead of a black box.

Core principles

  • Full control over compilation flags.
  • Minimal unnecessary software.
  • Declarative package recipes.
  • Reproducible and verifiable builds.
  • Cryptographically verified repositories.
  • Stable and predictable system behavior.

Base system

Summit is aimed at experienced Linux users and follows an LFS/source-build model.

Our mission

Give experienced users a system they can fully explain: every binary traces back to a readable recipe, every repository index carries a verifiable signature, and nothing is installed that the user did not ask for.

Goal: a minimal, auditable base you can rebuild from scratch on any machine.

Summit Linux features

  • Source-first: LFS-based toolchain with declarative build recipes.
  • Minimal base: CLI-only default install, no hidden services.
  • Your init, your choice: OpenRC / sysvinit with optional runit.
  • Reproducible builds: fixed flags, isolated build environment, checksummed sources.
  • Signed everything: repository indexes, releases and recipes are cryptographically verified.
  • Downgrade protection: version checks and expiry dates on repository metadata.

picu stack

picu is written in Rust and combines source recipes with binary packages: it fetches signed indexes, resolves dependencies, builds in isolation with picu cook, and installs transactionally into a tracked file registry.

$ picu --version
picu 0.1.0 (rust, ed25519, sha256)
$ picu trust list
[ OK ] release key: summit-release-01
[ OK ] 1 mirror trusted, 0 revoked
