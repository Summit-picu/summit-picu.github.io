      v0.3.0 — 2026-10-01

      Trust management and documentation refresh.

      • picu trust key rotation with threshold 2 (old + new key) and revoked certificates list.
      • Repository index expiry checks (ExpireDate) on every sync.
      • Site refresh: wiki TOC, FAQ, status page and breadcrumbs across all pages.
      • Official mirror with signed repo.index.json — coming soon (not available yet).

      v0.1.0 — 2026-08-12

      Initial concept release.

      • LFS-based base system plan and staged implementation roadmap.
      • picu MVP: sync, add, update, find, info against a trusted index.
      • Site skeleton: home, about, download, picu and wiki stub pages.
