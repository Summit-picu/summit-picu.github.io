Что такое Summit Linux

Summit Linux — независимый дистрибутив Linux, собранный из исходного кода по принципам Linux From Scratch: прозрачные компоненты, контролируемые сборки и минимум лишнего ПО.

Философия: прозрачность вместо магии, рецепт вместо чёрного ящика.

Раздел в разработке — скоро будет.

Быстрый старт

Повседневная работа в три команды: синхронизировать индексы, поставить пакет, обновить систему.

$ picu sync
[ OK ] sync completed successfully
$ picu add vim
[ OK ] finding in mirror
[ OK ] installing Vim
$ picu update
[ OK ] system up to date

Команды

picu управляет репозиториями, рецептами сборки, бинарными пакетами, подписями, хранилищем доверия и базой пакетов.

  • picu sync — получить индексы репозиториев и проверить подписи.
  • picu add <pkg> — установить пакет с доверенного зеркала.
  • picu cook <recipe> — собрать пакет из исходников в изоляции.
  • picu cut <pkg> — удалить пакет и убрать бесхозные остатки.
  • picu find <query> — поиск пакетов по индексам репозиториев.
  • picu list — показать установленные пакеты.
  • picu info <pkg> — версия, рецепт и зеркало пакета.
  • picu update — обновить пакеты до последних доверенных версий.
  • picu rebase <recipe> — пересобрать локальный рецепт на текущем базисе.
  • picu trust list — доверенные ключи и отозванные сертификаты.
$ picu cook ./recipes/vim.toml
[ OK ] isolated build finished

Частые вопросы

Summit Linux готов для ежедневного использования?

Проект — рабочая концепция с поэтапным планом реализации; следите за страницей новостей.

Чем picu отличается от других менеджеров пакетов?

picu сочетает рецепты из исходников и бинарные пакеты с криптографической проверкой каждого индекса репозитория.

Какая init-система используется?

OpenRC / sysvinit с опциональным runit.

Как проверить загрузки?

Релизы будут снабжены контрольными суммами, а индексы репозиториев будут подписаны; подробности — на странице скачивания.

Можно ли собирать пакеты из исходников?

Да — команда picu cook с файлом рецепта выполняет изолированную воспроизводимую сборку.

Где полная документация?

В репозитории Markdown-files-and-info и на странице скачивания.

Какие команды picu нужны чаще всего?

picu sync, picu add, picu update, picu find и picu info для повседневной работы; picu cook и picu cut для сборки из исходников; picu trust для управления ключами.

Как добавить зеркало сообщества?

Добавьте его описание в /etc/picu/mirrors.d/ и выдайте явное доверие — зеркала сообщества никогда не доверенные по умолчанию.

Что делать, если проверка подписи не прошла?

Ничего не ставьте: повторите picu sync, проверьте срок действия индекса и доверенные ключи, затем сообщите о зеркале.
