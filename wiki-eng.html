What is Summit Linux

Summit Linux is an independent Linux distribution built from source following Linux From Scratch principles: transparent components, controlled builds and minimal software.

Philosophy: transparency instead of magic, a recipe instead of a black box.

Quick start

Daily workflow in three commands: sync indexes, install a package, upgrade the system.

$ picu sync
[ OK ] sync completed successfully
$ picu add vim
[ OK ] finding in mirror
[ OK ] installing Vim
$ picu update
[ OK ] system up to date

Commands

picu manages repositories, build recipes, binary packages, signatures, trust stores and the package database.

  • picu sync — fetch repository indexes and verify signatures.
  • picu add <pkg> — install a package from a trusted mirror.
  • picu cook <recipe> — build a package from source in isolation.
  • picu cut <pkg> — remove a package and clean up untracked leftovers.
  • picu find <query> — search repository indexes for packages.
  • picu list — show installed packages.
  • picu info <pkg> — show version, recipe and mirror details.
  • picu update — upgrade installed packages to the latest trusted versions.
  • picu rebase <recipe> — rebuild a local recipe against the current base.
  • picu trust list — show trusted keys and revoked certificates.
$ picu cook ./recipes/vim.toml
[ OK ] isolated build finished

FAQ

Is Summit Linux ready for daily use?

The project is a working concept with a staged implementation plan; follow the News page for releases.

How is picu different from other package managers?

picu combines source recipes and binary packages with cryptographic verification of every repository index.

Which init system does Summit use?

OpenRC / sysvinit with an optional runit setup.

How do I verify downloads?

Releases will be checksummed and repository indexes will be signed; see the Download page for details.

Can I build packages from source?

Yes — use picu cook with a recipe file for an isolated, reproducible build.

Where is the full documentation?

In the Markdown-files-and-info repository and on the Download page.

Which picu commands will I use most?

picu sync, picu add, picu update, picu find and picu info for daily work; picu cook and picu cut for source builds; picu trust for key management.

How do I add a community mirror?

Add its description to /etc/picu/mirrors.d/ and grant it explicit trust — community mirrors are never trusted by default.

What if a signature check fails?

Do not install anything: re-run picu sync, check the index expiry date and your trusted keys, then report the mirror.
