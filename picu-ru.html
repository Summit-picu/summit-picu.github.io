picu

picu — пакетный менеджер, лежащий в основе Summit Linux. Он отвечает за сборку из исходников, бинарные пакеты, репозитории, подписи и метаданные пакетов.

Source code GitHub mobile

Основные команды 

picu add <pkg>
picu cook <pkg>
picu cut <pkg>
picu find <query>
picu sync
picu rebase
picu list
picu info <pkg>
picu update
picu trust
picu help

Сборка из исходников

Пакеты описываются с помощью декларативных рецептов .picu .

Бинарные пакеты

picu умеет устанавливать подписанные бинарные архивы после проверки их хешей и подписей.

Доверие

Небезопасные репозитории заблокированы по умолчанию.
Для установки из небезопасного зеркала требуется явный флаг --allow-unsafe .
