Summit Linux — это независимый дистрибутив Linux, собираемый из исходного кода по принципам Linux From Scratch.

Философия: прозрачность вместо магии, рецепт вместо чёрного ящика.

Основные принципы

  • Полный контроль над флагами компиляции.
  • Минимум лишнего программного обеспечения.
  • Декларативные рецепты пакетов.
  • Воспроизводимые и проверяемые сборки.
  • Криптографически проверенные репозитории.
  • Стабильное и предсказуемое поведение системы.

Базовая система

Summit ориентирован на опытных пользователей Linux и построен по модели LFS/сборки из исходников.

КомпонентSummit
ОсноваLFS / На основе исходников
Пакетный менеджерpicu
АудиторияОпытные пользователи и администраторы
Init-системаOpenRC / sysvinit / опционально runit
Окружение по умолчаниюМинимальный CLI

Наша миссия

Дать опытным пользователям систему, которую можно полностью объяснить: каждый бинарник восходит к читаемому рецепту, каждый индекс репозитория несёт проверяемую подпись, и ничего не ставится без ведома пользователя.

Цель: минимальный проверяемый базис, который можно пересобрать с нуля на любой машине.

Возможности Summit Linux

  • Исходники прежде всего: LFS-тулчейн и декларативные рецепты сборки.
  • Минимальный базис: установка с CLI по умолчанию, без скрытых сервисов.
  • Init на выбор: OpenRC / sysvinit с опциональным runit.
  • Воспроизводимые сборки: фиксированные флаги, изолированное окружение, контрольные суммы исходников.
  • Всё подписано: индексы репозиториев, релизы и рецепты проверяются криптографически.
  • Защита от отката: проверка версий и сроков действия метаданных репозиториев.

Стек picu

picu написан на Rust и сочетает рецепты из исходников с бинарными пакетами: получает подписанные индексы, разрешает зависимости, собирает в изоляции командой picu cook и ставит транзакционно с учётом файлов в реестре.

$ picu --version
picu 0.1.0 (rust, ed25519, sha256)
$ picu trust list
[ OK ] release key: summit-release-01
[ OK ] 1 mirror trusted, 0 revoked
